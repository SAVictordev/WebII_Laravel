# Desenvolvimento para Web II — Laravel

Repositório destinado aos estudos, atividades e projetos desenvolvidos durante a disciplina **Desenvolvimento para Web II**.

O objetivo deste repositório é registrar minha evolução no aprendizado do framework **Laravel**, explorando seus principais recursos, conceitos e ferramentas para o desenvolvimento de aplicações web utilizando PHP.

##  Sobre a disciplina

Durante a disciplina serão desenvolvidos exercícios e aplicações práticas utilizando o **Laravel**, buscando compreender não apenas o funcionamento do framework, mas também conceitos importantes relacionados ao desenvolvimento web e à organização de aplicações.

Entre os principais assuntos estudados estão:

* Arquitetura **MVC (Model-View-Controller)**
* **Routes** e definição de rotas
* **Controllers**
* **Models**
* **Migrations**
* **Seeders**
* **Factories**
* **Blade**
* Eloquent ORM
* Relacionamentos entre Models
* Formulários e validações
* Requisições HTTP
* Middlewares
* Autenticação e autorização
* Banco de dados
* CRUD
* Estrutura e organização de projetos Laravel
* Outros recursos e conceitos relacionados ao desenvolvimento web

##  Tecnologias utilizadas

##  Objetivos

Este repositório tem como principais objetivos:

* Aprender e praticar o framework Laravel;
* Compreender a arquitetura MVC;
* Desenvolver aplicações web utilizando PHP e Laravel;
* Aprender a trabalhar com bancos de dados através do Eloquent ORM;
* Praticar a criação e gerenciamento de migrations;
* Utilizar Seeders e Factories para criação de dados;
* Desenvolver Controllers e Routes;
* Criar operações CRUD;
* Compreender a organização de uma aplicação Laravel;
* Aplicar boas práticas de desenvolvimento;
* Registrar a evolução dos estudos durante a disciplina.


##  Conteúdos estudados

O repositório acompanhará a evolução dos estudos, incluindo exemplos e atividades relacionadas a diferentes recursos do Laravel.

### MVC

Estudo da arquitetura **Model-View-Controller**, compreendendo a separação de responsabilidades entre as diferentes partes da aplicação.

### Routes

Criação e gerenciamento de rotas responsáveis por direcionar as requisições para os recursos apropriados da aplicação.

### Controllers

Desenvolvimento de Controllers para organizar a lógica responsável pelo processamento das requisições.

### Models e Eloquent

Utilização dos Models e do **Eloquent ORM** para representar e manipular os dados da aplicação.

### Migrations

Criação e gerenciamento da estrutura do banco de dados através das migrations do Laravel.

### Seeders

Utilização de Seeders para inserir dados iniciais ou dados de teste no banco de dados.

### Factories

Criação de dados fictícios para testes e desenvolvimento utilizando as Factories do Laravel.

### CRUD

Desenvolvimento das operações básicas de:

* **Create**
* **Read**
* **Update**
* **Delete**
